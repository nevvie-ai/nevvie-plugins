# Hipsy channel for Event Assistant (`nevvie-hipsy`)

Puts events prepared by `nevvie-events` on Hipsy. Depends on `nevvie-events`.

- Skills: `hipsy-scan` (setup step and read-only refresh), `publish` (rules check gate, then a hidden
  concept on Hipsy in the signed-in browser; the owner makes it live).
- Reference: `hipsy-template.md` (every field, same for all organisers), `hipsy.md` (API, dashboard,
  policy checklist).
