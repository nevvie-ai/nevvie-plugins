# nevvie-plugins

New here? Read [START-HERE.md](START-HERE.md) (Nederlands + English).

Nevvie's private Claude plugin marketplace for small businesses.

| Plugin | For |
|---|---|
| `nevvie-events` (Event Assistant for Hipsy organisers) | The base for every event business: folder, voice, setup, planning, emails |
| `nevvie-hipsy` (Hipsy channel) | Publishing on Hipsy (depends on the base) |
| `nevvie-fetlife` (FetLife channel) | Preparing events for FetLife (depends on the base) |

A business uses it from its own private folder (repo), whose `.claude/settings.json` adds this
marketplace and enables the plugin. See `plugins/nevvie-events/reference/business-folder.md` for
the folder the plugin expects.
